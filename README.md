Project Overview

This project is a beginner-friendly landing page developed as part of Level 1, Task 2 of the web development internship. It demonstrates the fundamentals of web page structure, styling, layout design, and responsive presentation.

Objectives

- Build a structured and visually appealing landing page.
- Practice HTML and CSS fundamentals.
- Use spacing, alignment, typography, and colors effectively.
- Create a user-friendly layout for different screen sizes.

Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

Features

- Navigation section
- Main hero section
- Organized content sections
- Call-to-action elements
- Responsive styling, where implemented

How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Locate "index.html".
4. Open "index.html" in a web browser, or run it using the Live Server extension.
